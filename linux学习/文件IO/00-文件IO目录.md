# 📑 文件 IO 学习目录

> 本目录将 `文件IO/` 下的 4 份 PDF 课件按主题整理为 Markdown 章节，方便在 Obsidian 中阅读、检索与双链跳转。4 份 PDF 为 Typora 渐进式导出（后一份包含前一份的全部内容），本次整理以最新的 `3.标准IO二.pdf`（共 30 页）为唯一数据源去重完成；原始 PDF 均保留在本目录，可随时对照。

## 🗺️ 学习路线

推荐按以下顺序学习，前一章是后一章的基础：

1. **第1章 系统IO** — Linux 内核提供的文件接口：open / read / write / close / lseek / umask
2. **第2章 目录操作** — 目录遍历、文件属性、删除与截短、工作路径，附 ls / cp 仿写作业
3. **第3章 标准IO** — 跨平台的标准文件接口：FILE 流、缓冲策略、fopen 与三种粒度读写
4. **第4章 标准IO二** — 缓冲冲洗、文件流定位、EOF 与错误标志、格式化输入输出

```text
系统IO ──► 目录操作 ──► 标准IO ──► 标准IO二
  (第1章)      (第2章)      (第3章)      (第4章)
```
