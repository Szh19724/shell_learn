# 📑 Linux 学习目录

> 本目录将 `linux学习/` 文件夹中的 5 份 PDF 课件,按推荐学习顺序整理为 Markdown 章节,方便在 Obsidian 中阅读、检索与双链跳转。原始 PDF 均保留在 `linux学习/` 目录,可随时对照。

## 🗺️ 学习路线

推荐按以下顺序学习,由浅入深,后一章会用到前一章的知识:

1. **第1章 Linux 简介与基础操作** — 先认识 Linux 是什么、熟悉 Ubuntu 设置与终端、了解文件系统与目录结构
2. **第2章 Linux 常用命令** — 一切操作的基础,务必多敲多练
3. **第3章 正则表达式** — 文本处理利器,是学好 Shell 脚本的前置技能
4. **第4章 Shell 脚本** — 把命令组合成自动化脚本,提升效率
5. **第5章 Makefile 工程管理文件** — 管理 C 语言等项目的编译流程

```text
Linux基础操作 ──► 常用命令 ──► 正则表达式 ──► Shell脚本 ──► Makefile
    (第1章)        (第2章)       (第3章)        (第4章)       (第5章)
```

## 📌 使用说明

- 每章开头有「本章要点」概览,章末有「小结与下一步」,可顺着双链一路学完。
- 章内知识点可直接用 Obsidian 搜索,或在任意笔记中用 `[[章节名]]` 双链引用。
- 命令与代码示例均为可复制的代码块;Makefile 示例需注意命令行必须以 Tab 开头。
- 原课件 PDF 页码如需核对,各章正文的引用块中注明了对应来源与页数。
