## 本章要点

- 正则表达式是用来描述某种规则字符的表达式，主要用于模糊搜索（查询）；字符串中的字符分为普通字符与元字符两类，元字符需要用 `\` 转义才能表示其本身。
- 掌握常用元字符的含义与示例：`.`、`[]`、`\w`、`+`（贪婪匹配）、`*`（惰性匹配）、`?`、`{数字}`、`{min,}`、`{min,max}`、`()`（子模式）。
- 能把 IP 地址（点分式字符串）的规则翻译成正则表达式，精简写法为 `([0-9]{1,3}\.){3}[0-9]{1,3}`。
- [ ] C/C++ 标准库（`<regex.h>`）提供 POSIX 正则 API：`regcomp` 编译、`regexec` 匹配、`regerror` 错误解析、`regfree` 清理，需掌握各参数含义与返回值。
- 课后作业：编写一个 C 程序，匹配字符串中的网址 `www.xxxxxx.xxx.com/cn/xyz`。

## 正则表达式

场景描述：比如你现在要写一个程序，其中有一个功能是匹配以一个日志文本中的IP地址。

```text
IP地址：xxx.xxx.xxx.xxx  点分式字符串
192.168.31.1

循环不断读取日志文本中字符
    判断 读取的字符是否为 字符0>= 并且 字符<=字符9
        提取出来
        判断下一位是不是点
            如果不是点就要计数
    判断计数值是否大于3，如果大于三说明这个不是一个IP地址
```

这样写就会逻辑很复杂。

正则表达式就是用来描述某种规则字符的表达式，主要用于模糊搜索（查询）

要查找IP地址可以按照规则搜索

分析IP地址的规则：

- 一共分为四段
- 每一段至少一个数字至多三个数字
- 两端中间会有一个点

正则表达式里面字符串中字符分为两类：

- 普通字符：只代表自己
    - `1 2 a b  ...`
- 元字符：不代表自己，有特殊含义(这个含义优先)
    - `. * ? + \ ...`

> 注意：元字符想要表示自己本身原来的意思的话，需要用 `\` 反斜杠进行转义

## 正则表达式中元字符

- `.`：表示匹配任意单个字符
    - 示例：

    ```text
    表达式：    .
    可以匹配到：a b 1 2 + ...
    ```

- `[]`：表示字符组
    - 字符组里面可以有多个普通字符，但是它只会去匹配其中一个
    - 示例：

    ```text
    表达式：[123456789] 表示在1~9的字符范围内去匹配一个
    可以匹配到：1 2 3 4 5 6 7 8 9
    表达式：[13579abcd] 表示在13579abcd的字符范围内去匹配一个
    可以匹配到：1 3 5 7 9 a b c d
    ```

    - 字符组可以用 `-` 来表示一个范围

    ```text
    [0123456789] 可以写成 [0-9]
    [abcdefghij] 可以写成 [a-j]

    其实就是按照ASCII码去列举范围
    ```

- `\w`：表示匹配字母、数字以及（`_` 下划线）
    - 示例：

    ```text
    表达式：\w 表示在0~9、a-z、A-Z、_这些字符范围内去匹配一个
    可以匹配到：0-9 a-z A-Z _
    ```

- `+`：表示匹配一个或多个先前字符或者是模式（贪婪匹配）
    - 示例：

    ```text
    表达式：\w+ 表示匹配一个或多个字母、数字、_
    可以匹配到：1 11 1111 ....
            ：12 12222 12315646
            ....
    表达式：1+ 表示匹配一个或多个1
    可以匹配到：1 11 111 1111 ....

    表达式：ab+ 表示先匹配a再匹配一个或多个b
    可以匹配到：ab abb abbb ...
    ```

- `*`：表示匹配零个或多个先前字符或模式（惰性匹配）
    - 示例：

    ```text
    表达式：ab* 表示先匹配a再匹配零个或多个b
    可以匹配到：a ab abb abbb ...
    ```

- `?`：表示匹配零个或一个先前字符或模式
    - 示例：

    ```text
    表达式：ab?
    可以匹配到：a ab
    ```

- `{数字}`：表示匹配固定数目的先前字符或模式
    - 示例：

    ```text
    表达式：a{5} 表示完成匹配到5个a
    可以匹配到：aaaaa
    ```

- `{min,}`：表示至少匹配 min 个先前字符或模式
    - 示例：

    ```text
    表达式：a{5,} 表示至少匹配到5个a
    可以匹配到：aaaaa aaaaaaaaaa aaaaaaaaaa ....
    ```

- `{min,max}`：表示至少匹配 min 个至多匹配 max 个先前字符或模式
    - 示例：

    ```text
    表达式：a{2,3} 表示至少匹配2个a，至多匹配3个a
    可以匹配到：aa aaa
    ```

- `()`：表示子模式，其内部表达式看成一个整体
    - 示例：

    ```text
    表达式：(12+)+  表示至少一个或多个(12或12222...）
    可以匹配到：12 122122 12221222....
    ```

分析IP地址的规则：

- 一共分为四段
- 每一段至少一个数字至多三个数字
- 两段中间会有一个点

匹配IP地址的正则表达式：

```text
// 先匹配点式字符串
[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+

// 匹配三个完整的分段
[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}

// 精简的表达式
([0-9]{1,3}\.){3}[0-9]{1,3}
```

## 正则表达式的API接口

```c
#include <regex.h>

// 正则表达式的接口头文件
int regcomp(regex_t *preg, const char *regex, int cflags);

int regexec(const regex_t *preg, const char *string, size_t nmatch,regmatch_t pmatch[], int eflags);

size_t regerror(int errcode, const regex_t *preg, char *errbuf,size_t errbuf_size);

void regfree(regex_t *preg);
```

## 编译正则表达式

```c
int regcomp(regex_t *preg, const char *regex, int cflags);
/*
    功能：
        用来编译 "正则表达式" 的。编译完成的正则表达式用regex_t 类型表示
        "正则表达式"原始字符串（手写的正则表达式）编译完成之后 regex_t 类型
    @preg:
        regex_t *类型
        指向空间，就是用来保存编译后的正则表达式的。
    @regex:
        const char *类型
        指向空间是存储原始字符串（正则表达式）的。没有被编译过的正则表达式字符串
    @cflags:
        int 类型
        标志位：
            REG_EXTENDED 用来扩展正则表达式的语法
            REG_ICASE    ignore case 忽略大小写
            REG_NOSUB    不包含子模式
            以上标志位都是可以通过|运算符进行结合的
    @return:
        返回值为0表示无错误。
        返回值不为0表示错误，该返回值为一个错误码，需要通过regerror去进行错误解析
*/
```

## 进行正则表达式的匹配

```c
int regexec(const regex_t *preg, const char *string, size_t nmatch,regmatch_t pmatch[], int eflags);
/*
    功能：
        用于匹配正则表达式所描述的模式
    @preg:
        正则表达式，匹配模式。（也就是编译好了正则表达式，一般由regcomp赋值）
    @string:
        const char *类型
        原始字符串（母串）。需要进行匹配的原始字符串
    @nmatch:
        size_t 类型
        提前告知有多少个模式，总模式=（1个）+子模式数量
    @pmatch:
        regmatch_t 类型数组
        描述匹配结果，返回的是在母串中匹配到的下标范围，起始下标~结束下标
        typedef struct
        {
            regoff_t rm_so;    // rm_so : start offset 起始位置下标
            regoff_t rm_eo;    // rm_eo : end offset 终止下标
        } regmatch_t;

        模式匹配信息数组
        数组大小为nmatch大小
            一个模式就需要有一个regmatch_t
            指定了多少模式就有多少个regmatch_t
    @eflags:
        int 类型
        表示是否匹配行首或行尾，一般为0
    @return:
        返回值为0表示匹配到了数据
        返回值为REG_NOMATCH表示失败
*/
```

## 错误解析

```c
size_t regerror(int errcode, const regex_t *preg, char *errbuf,size_t errbuf_size);
/*
    功能：
        用来把regcomp和regexec函数执行返回的错误进行解析的，转换为错误信息字符串的
    @errcode:
        int 类型
        错误码。也就是需要进行解析的错误码
    @preg:
        const regex_t *类型
        编译好的正则表达式
    @errbuf:
        char *类型
        指向的空间用于保存解析错误信息之后，存储错误信息字符串的
    @errbuf_size:
        size_t 类型
        表示errbuf大小
    @return:
        返回值为填充到errbuf中的错误提示信息的字符串长度
*/
```

## 正则表达式清理

```c
void regfree(regex_t *preg);
/*
    功能：
        释放preg指向的那个空间
    @preg:
        就是编译后的正则表达式
*/
```
