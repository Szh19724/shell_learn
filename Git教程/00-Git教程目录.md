# 菜鸟教程 Git 教程

> 来源：[菜鸟教程 · Git 教程](https://www.runoob.com/git/git-tutorial.html)　·　归档日期：2026-10-24

本目录收录原站 `/git/` 下的全部 40 个教程页面，每页拆成一篇 Markdown。编号采用原站每页底部“上一篇 / 下一篇”链接形成的阅读顺序。

原站左侧栏只展示 16 个教程章节；另外 23 个 `git *` 命令页从《Git 基本操作》的表格和页底链接进入，`GitCode 使用教程` 则接在命令序列之后。为避免漏页，本目录把这 40 个页面全部收录。

## 使用说明

- 每篇保留原文的标题层级、段落、表格、命令示例和正文配图；图片已下载到 `assets/`，离线也能查看。
- 页面底部的“系列导航”可以按原站顺序前后翻阅；本页是总目录。
- 原文中的站内链接已改为本目录中的对应文档，站外链接保留为完整网址。
- “Git 测验”页把原站动态加载的题目整理为静态题目，答案放在可折叠区域。
- 教程内容的著作权归菜鸟教程（runoob.com）及原作者所有；本目录仅用于个人学习与离线阅读，请勿用于商业传播。
