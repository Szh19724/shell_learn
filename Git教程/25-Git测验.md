# Git 测验

> 来源：[菜鸟教程 · Git 测验](https://www.runoob.com/git/git-quiz.html)　·　系列第 25 / 40 篇

本页原站提供 9 道交互式选择题。以下保留全部题目，并将答案与解析折叠，便于自测。

## 第 1 题

Git 是什么？

- **A.** Git 是 SVN
- **B.** Git 是 Github 的简写
- **C.** 是编程语言
- **D.** 分布式版本控制系统

<details>
<summary>查看答案</summary>

**答案：D. 分布式版本控制系统**

解析：Git 是一个分布式版本控制系统。

</details>

## 第 2 题

将仓库从 GitHub 下载到本地的 git 命令是什么？

- **A.** git push
- **B.** git fork
- **C.** git clone
- **D.** git commit

<details>
<summary>查看答案</summary>

**答案：C. git clone**

</details>

## 第 3 题

如何将本地仓库上传到远程仓库？

- **A.** git push
- **B.** git add
- **C.** git upload
- **D.** git status

<details>
<summary>查看答案</summary>

**答案：A. git push**

解析：git push 可以将本地仓库上传到远程仓库。

</details>

## 第 4 题

提交修改先使用以下哪个命令？

- **A.** git add
- **B.** git commit

<details>
<summary>查看答案</summary>

**答案：A. git add**

解析：commit 之前需要使用 git add 命令将该文件添加到暂存区。

</details>

## 第 5 题

以下哪个命令是正确的提交所有更改的注释？

- **A.** git message -am "I'm coding"
- **B.** git add -a "I'm coding"
- **C.** git commit -a "I'm coding"
- **D.** git commit -am "I'm coding"

<details>
<summary>查看答案</summary>

**答案：D. git commit -am "I'm coding"**

</details>

## 第 6 题

以下哪个命令是正确的提交注释？

- **A.** git message "I like runoob"
- **B.** git add "I like runoob"
- **C.** git commit "I like runoob"
- **D.** git commit -m "I like runoob"

<details>
<summary>查看答案</summary>

**答案：D. git commit -m "I like runoob"**

</details>

## 第 7 题

以下哪个命令是将所有修改提交到暂存区？

- **A.** git commit add .
- **B.** git commit .
- **C.** git add .
- **D.** git push -am "Message"

<details>
<summary>查看答案</summary>

**答案：C. git add .**

</details>

## 第 8 题

以下哪个命令用于查看在你上次提交之后是否有对文件进行再次修改？

- **A.** git check
- **B.** git status
- **C.** git commit
- **D.** git diff

<details>
<summary>查看答案</summary>

**答案：B. git status**

</details>

## 第 9 题

以下哪个命令用于提交到暂存区？

- **A.** git stage
- **B.** git commit
- **C.** git add
- **D.** git reset

<details>
<summary>查看答案</summary>

**答案：C. git add**

</details>
