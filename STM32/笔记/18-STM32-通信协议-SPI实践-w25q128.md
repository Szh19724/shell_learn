# 18 STM32-通信协议-SPI实践-w25q128

> 本课整理自 `10.2通信协议-SPI实践-w25q128.pdf`(共 12 页)。返回 [[STM32学习目录|📑 STM32学习目录]]。

## 本章要点

- 本课完整给出 W25Q 系列 SPI Flash 的驱动文件源码:`w25qxx.h`(接口、ID、指令表)与 `w25qxx.c`(实现)。
- 头文件定义芯片 ID(W25Q80~W25Q128 为 `0XEF13`~`0XEF17`)、CS 片选宏与 W25X 指令表(写使能 `0x06`、读数据 `0x03`、页编程 `0x02`、扇区擦除 `0x20`、整片擦除 `0xC7` 等)。
- 所有收发都经 `W25QXX_SPI_ReadWriteByte()` → `HAL_SPI_TransmitReceive()` 完成,每次命令传输用 CS 拉低/拉高框定。
- 读写遵循"命令 + 24 位地址 + 数据"帧格式;写前必须写使能(WEL=1),写/擦后轮询状态寄存器 BUSY 位直到空闲。
- 带擦除的写入以 4KB 扇区为单位:读出整扇区 → 检查是否全为 0xFF → 需要则擦除 → 合并新数据 → 整扇区写回。
- 容量用 SFDP 命令 `0x5A` 读取并按 `(读取值+1) >> 3` 计算;唯一 ID 用 `0x4B` 读 8 字节;掉电/唤醒(`0xB9`/`0xAB`)后需延时至少 3us。

// 微秒级延时函数
static void delay_us(uint32_t us)
{
    uint32_t delay = (HAL_RCC_GetHCLKFreq() / 4000000 * us); // 计算需要延时的循环次数
    while (delay--) { // 执行空循环实现延时
        ;
    }

// SPI读写一个字节
// TxData: 要写入的字节
// 返回值: 读取到的字节
static uint8_t W25QXX_SPI_ReadWriteByte(uint8_t TxData)
{
    uint8_t RxData = 0X00; // 用于存储接收到的数据

    // 通过SPI发送并接收1个字节，超时时间为10ms
    if(HAL_SPI_TransmitReceive(W25QXX_SPI_Handle, &TxData, &RxData, 1, 10) != HAL_OK){
        RxData = 0XFF; // 如果传输失败，返回0xFF
    }
    return RxData; // 返回接收到的数据
}

// 初始化SPI Flash的IO口
int W25QXX_Init(void)
{
    MX_SPI1_Init(); // 初始化SPI1外设
    W25QXX_CS_L(); /* 拉低片选信号，选中Flash芯片 */
    W25QXX_SPI_ReadWriteByte(0XFF); // 发送一个空字节，用于初始化SPI通信
    W25QXX_CS_H(); /* 拉高片选信号，取消选中 */

    // 读取Flash芯片ID并存储到全局变量
    W25QXX_TYPE = W25QXX_ReadID();
    // 读取Flash芯片容量并存储到全局变量
    W25QXX_SIZE = W25QXX_ReadCapacity();

// 读取W25QXX的状态寄存器
// 状态寄存器位描述:
// BIT7 6 5 4 3 2 1 0
// SPR RV TB BP2 BP1 BP0 WEL BUSY
// SPR: 状态寄存器保护位,配合WP引脚使用
// TB,BP2,BP1,BP0: Flash区域写保护设置
// WEL: 写使能锁定标志(1:允许写操作)
// BUSY: 忙标记位(1:忙;0:空闲)
// 默认值: 0x00
uint8_t W25QXX_ReadSR(void)
{
    uint8_t byte = 0; // 用于存储读取到的状态寄存器值

    W25QXX_CS_L(); // 拉低片选，选中器件
    W25QXX_SPI_ReadWriteByte(W25X_ReadStatusReg); // 发送读取状态寄存器命令
    byte = W25QXX_SPI_ReadWriteByte(0Xff); // 读取一个字节的状态寄存器值
    W25QXX_CS_H(); // 拉高片选，取消片选
    return byte; // 返回读取到的状态
}

// NumByteToWrite: 要写入的字节数(最大256), 该数不应超过该页的剩余字节数

{

    W25QXX_CS_L(); // 使能器件(拉低片选)

    W25QXX_SPI_ReadWriteByte((uint8_t)((WriteAddr) >> 8)); // 地址中8位
    W25QXX_SPI_ReadWriteByte((uint8_t)WriteAddr); // 地址低8位

// 写SPI FLASH
// 在指定地址开始写入指定长度的数据
// 该函数带擦除操作!
// pBuffer: 数据存储区指针
// WriteAddr: 开始写入的地址(24bit)
// NumByteToWrite: 要写入的字节数(最大65535)
uint8_t W25QXX_BUFFER[4096]; // 扇区缓冲区(一个扇区4096字节)

void W25QXX_Write(uint8_t *pBuffer, uint32_t WriteAddr, uint16_t NumByteToWrite)
{
    uint32_t secpos; // 扇区地址
    uint16_t secoff; // 扇区内偏移地址
    uint16_t secremain; // 扇区内剩余空间
    uint16_t i; // 循环计数器
    uint8_t *W25QXX_BUF; // 临时指针，指向扇区缓冲区

    W25QXX_BUF = W25QXX_BUFFER; // 指向全局扇区缓冲区

    secpos = WriteAddr / 4096; // 计算扇区地址(一个扇区4096字节)
    secoff = WriteAddr % 4096; // 计算在扇区内的偏移
    secremain = 4096 - secoff; // 计算扇区内剩余空间大小

    // 如果写入长度小于扇区剩余空间，调整secremain

## 小结与下一步

- 本课逐页给出 W25Q 系列 Flash 驱动的完整源码:`w25qxx.h` 负责 ID/指令/接口声明,`w25qxx.c` 实现字节收发、初始化校验与全部读写擦操作。
- 统一时序:"拉低 CS → 命令 → 24 位地址 → 数据 → 拉高 CS → 等待 BUSY";写前先写使能,目标区域非 0xFF 时必须先擦除。
- 写入分三层封装:页编程(≤256B)→ 无校验自动换页写 → 带擦除的 4KB 扇区级写入,上层调用只需给地址与长度。
- 状态寄存器的 BUSY/WEL 位是驱动的同步核心:`W25QXX_Wait_Busy()` 轮询 BUSY,写使能/写禁止控制 WEL。
