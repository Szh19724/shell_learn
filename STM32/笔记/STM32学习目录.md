# 📑 STM32 课件笔记学习目录

> 本目录将 `STM32/` 文件夹中全部 22 讲课程 PDF(4 个散装 PDF + 18 个藏在课程 ZIP 内的课件 PDF)按课程原编号整理为 Markdown 笔记,图片已从 PDF 中提取并插入正文。原始 PDF 与工程 ZIP 均保留在 `STM32/` 目录,可随时对照。

## 🗺️ 学习路线

课程编号沿用原课时序号(无第 2 讲),建议按以下顺序学习:

```text
内核架构基础 ──► 外设与工程 ──► 中断/系统滴答 ──► 定时器家族 ──► 异步通信
   (00、01)        (03、04)        (05、06)         (07~11)        (12)
                                                                        │
数据搬运与看门狗 ◄── 模拟外设 ◄── FSMC ◄── SPI ◄── IIC ◄───────────────┘
      (21、22)        (20)        (19)     (16~18)   (13~15)
```

1. **内核架构基础(00~01)** — 先建立计算机组成、指令系统与 ARM 指令集的前置概念
2. **外设与工程(03~04)** — STM32 总体架构、时钟树,以及工程建立与程序下载
3. **中断与系统滴答(05~06)** — NVIC、中断优先级、SysTick
4. **定时器家族(07~11)** — 基本 → 通用(PWM/编码器) → 高级(死区/刹车) → RTC
5. **异步通信(12)** — 串口通信概念、RS232/RS485、波特率与流控
6. **IIC 总线(13~15)** — 协议流程、错误处理,再落到 AT24C02/OLED 实践
7. **SPI 总线(16~18)** — 时序与系统框图,再落到 W25Q128 实践
8. **存储扩展与模拟外设(19~20)** — FSMC 驱动 LCD、ADC 各转换模式
9. **数据搬运与系统保护(21~22)** — DMA 传输、IWDG/WWDG 看门狗
